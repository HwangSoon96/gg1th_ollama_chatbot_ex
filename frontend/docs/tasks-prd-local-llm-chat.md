### 참고
- 테스트: `vitest` + `@testing-library/react` (devDependency 추가).
  - 이유: 분기·파싱 로직(에러 정규화, 맥락 접기, 용량 트리밍)은 테스트 필수 대상.
  - `@testing-library/react` + `jsdom` (3.0에서 추가): 훅의 상태 전이를 검증하려면 DOM이 필요.
    전역 환경으로 두지 않고 훅 테스트 파일에만 `@vitest-environment jsdom`을 붙인다 —
    전역으로 바꾸면 fetch를 모킹하는 `chatApi.test.js`가 영향을 받는다.
- **패키지 매니저는 `npm`** (`package-lock.json` 기준). pnpm 미설치.

### 이 환경의 특이사항 (재현용)
- gjc `browser` 툴이 이 WSL2 환경에서 워커 기동 실패 → CDP 직접 제어로 대체.
  스크린샷 스크립트: `/tmp/shot.mjs` (`node shot.mjs <url> <out> <w> <h> <theme>`)
- 백그라운드 프로세스가 bash 호출 사이에 종료됨 → **dev 서버 기동 + 크롬 기동 + 촬영을
  한 번의 bash 호출 안에서** 처리해야 함. `setsid`/`nohup`으로도 유지 안 됨.
- 크롬은 `--no-sandbox --disable-dev-shm-usage` 필요.
